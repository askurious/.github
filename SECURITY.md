# Security

This is the default security policy of the Askurious organisation; a repository with its own SECURITY.md follows that one.

## Reporting a vulnerability

Please report security issues privately, not in public issues or pull requests: through GitHub's "Report a vulnerability" button on the Security tab of the repository concerned, or by mail to Philipp Brauner (brauner@comm.rwth-aachen.de) or Ralf Philipsen (philipsen@comm.rwth-aachen.de). Describe what you found, how to reproduce it and which release or commit you looked at.

We confirm receipt within a few working days, keep you informed, and name you in the release notes if you wish. Please give us reasonable time to fix the issue before you make it public.

For a problem with a particular installation (for example askurious.de), use the contact in that installation's legal notice ("Impressum").

## Deutsch, kurz

Sicherheitslücken bitte vertraulich melden: über „Report a vulnerability“ im Reiter Security des betroffenen Repositorys oder per Mail an Philipp Brauner oder Ralf Philipsen, nicht in öffentlichen Issues oder Pull Requests.
